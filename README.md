🌍 Natural Disaster Management Website
A responsive and informative website designed to spread awareness, provide emergency resources, and assist in managing natural disaster situations. This project was developed as part of a Hackfest using only HTML, CSS, and JavaScript.

🔍 Project Overview
The Natural Disaster Management website aims to:
Educate users about different types of natural disasters
Provide safety tips and emergency contact information
Offer real-time updates (simulated) and preparedness checklists
Create an accessible, easy-to-use interface for people of all ages

🚀 Features
📄 Informational pages on various natural disasters (earthquakes, floods, cyclones, etc.)
✅ Preparedness guides and safety tips
🆘 Emergency contact section
📱 Fully responsive design for mobile and desktop
🌐 Simple, fast-loading frontend built with:

HTML for structure
CSS for styling
JavaScript for interactivity
